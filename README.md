🎬 JioHotstar Clone — Streaming Platform UI
A responsive streaming platform user interface inspired by JioHotstar, developed using HTML5 and CSS3. The project focuses on creating a modern streaming website layout with multiple pages, content cards, navigation, responsive design, and CSS animations.
🚀 Features
- Home page with hero/banner sections
- Movies section
- TV section
- Sports section
- Search page
- Categories page
- My Space page
- Watch page
- Content cards and promotional sections
- Responsive layout for different screen sizes
- Mobile navigation menu
- Hover effects and transitions
- CSS animations
- Video-watching interface
🛠️ Technologies Used

🎨 UI Features
🏠 Hero Section
Designed a large hero/banner section to highlight featured content with promotional information and call-to-action elements.
🎬 Content Cards
Created reusable content card layouts for displaying movies, TV shows, sports, and other streaming content.
📱 Responsive Design
Implemented responsive layouts using CSS media queries to adapt the interface to different screen sizes.
🍔 Mobile Navigation
Implemented a CSS-based mobile navigation menu for smaller screen sizes.
✨ Animations & Effects
Used CSS transitions, hover effects, transforms, and animations to make the interface more interactive.
▶️ Watch Interface
Created a dedicated watch page with a video-watching interface using HTML5 video functionality.
